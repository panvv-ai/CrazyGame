## 2. 产品目标

最终产品只保留以下主链路：

```text
行情数据
  → 股票/基金自选
  → 加权组合
  → 单账户持仓
  → 价格/涨跌幅提醒
  → 飞书/短信通知
  → 每日持仓健康简报
```

验收范围：

- 支持 A 股、港股、美股股票。
- 支持 A 股场内 ETF。
- 支持场外开放式基金/ETF 联接；界面明确区分盘中估值和正式净值。
- 股票和基金分别有自选清单。
- 任意自选标的可以混合组成权重 group。
- 提供单账户轻量持仓。
- 支持价格和当日涨跌幅提醒。
- 每个提醒可以选择飞书或阿里云短信渠道。
- 所有历史行情使用折线/面积图，不提供 K 线图。
- 默认简体中文，可切换英文；简报和通知跟随界面语言。
- 提供 `docker compose` 部署。

## 5. 行情数据与合规边界

### 5.1 当前数据路径

当前项目调用的是腾讯、新浪、东方财富、天天基金、Yahoo/Stooq 的公开网页接口，不是交易所正式授权行情 API。

| 标的 | 行情主源 | 历史数据 | 备用源 |
|---|---|---|---|
| A 股 | 腾讯报价 | 腾讯日线 | 东方财富 |
| 港股 | 腾讯报价 | 腾讯日线 | 东方财富、Yahoo |
| 美股 | 腾讯报价 | 腾讯日线 | 新浪实时价、Stooq/Yahoo |
| A 股 ETF | 腾讯/东方财富 | 交易价格或基金净值 | 东方财富 IOPV、折溢价、规模 |
| 场外基金 | 天天基金盘中估值 | 东方财富基金净值 | 最近正式净值 |

### 5.2 产品必须表达的事实

- 页面展示每项数据的 `as_of` 时间。
- 数据不是交易所授权逐笔行情时，不标记为“官方实时”。
- 场外基金盘中值标记为“估算”，正式值标记为“净值”。
- 数据源不可用时显示陈旧状态和最后成功时间。
- Group 收益率展示行情覆盖率，不把缺失值当作 0。

### 5.3 风险控制

- 不绕过登录、验证码、付费墙或访问限制。
- 使用批量请求、缓存、市场时段判断和低频轮询，避免打爆公开接口。
- 私有自用部署默认只监听本机或私有网络；如暴露公网必须启用认证和反向代理。
- 不对外提供公共行情 API，不向第三方转发行情数据。
- 不将 AI 简报包装成面向他人的投资顾问服务。
- 保留数据源可插拔能力；以后可以接入 Tushare、券商 API 或正式授权行情。
- 当前方案不购买正式行情授权，因为需求是私有、单用户、长期投资辅助。

## 6. 后端与数据模型

### 6.1 新数据库

使用 `DATA_DIR/panwatch-v2.db`：

- 不读取旧 `panwatch.db` 的业务数据。
- 不删除旧数据库。
- 新版本首次启动只初始化 v2 schema。
- 旧数据库可继续留作手工查询或从归档 tag 启动旧版本。

### 6.2 核心模型

- `Instrument`
  - `symbol`
  - `name`
  - `market`: `CN | HK | US | FUND`
  - `asset_type`: `stock | listed_etf | open_end_fund`
  - `currency`: `CNY | HKD | USD`
  - `quote_mode`: `realtime | estimated | nav`
- `WatchlistItem`
  - `instrument_id`
  - `kind`: `stock | fund`
  - `sort_order`
- `AssetGroup`
  - `name`
  - `description`
  - `sort_order`
- `GroupMember`
  - `group_id`
  - `instrument_id`
  - 非负相对权重
- `Holding`
  - 单组合内的 `instrument_id`
  - `quantity`
  - `average_cost`
  - `note`
- `AlertRule`
  - `instrument_id`
  - `metric`: `price | change_pct`
  - `direction`: `above | below`
  - `threshold`
  - `channel_ids`
  - `once_per_day`
  - `market_hours_only`
- `AlertHit`
  - 规则、标的、触发时间、实际值、行情快照
  - 各通知渠道的投递状态
- `NotifyChannel`
  - `feishu | aliyun_sms`
  - 凭据加密存储，读取接口只返回掩码
- `DailyReview`
  - 交易日、语言、持仓快照、市场快照
  - Markdown 内容、模型、生成状态
  - 通知状态和错误信息
- `AppSettings`
  - 界面语言
  - AI 服务配置
  - 简报时间和通知渠道

### 6.3 计算规则

- Group 保存正相对权重。
- 保存时按权重总和自动归一化。
- 当日涨跌为 `Σ(归一化权重 × 成分当日涨跌幅)`。
- 历史曲线基准值为 100，按目标权重逐交易日再平衡。
- 跨市场 Group 使用本币收益率，不把汇率变化计入投资收益。
- 场外基金历史曲线使用正式净值；当日卡片可使用盘中估值并明确标识。
- 部分标的没有行情时，按可用标的重新归一化计算，同时返回覆盖率。

### 6.4 刷新策略

- 页面可见时每 30 秒批量刷新一次。
- 页面隐藏时暂停轮询，重新可见时立即刷新一次。
- 只刷新当前处于交易时段的市场。
- 交易时段外停止轮询，使用最近收盘或最近净值。
- 使用交易日历处理周末、法定节假日和提前收盘。

## 7. 公开 API

除健康检查和版本外，所有接口位于 `/api` 且要求登录。

| 接口 | 用途 |
|---|---|
| `GET /api/instruments/search` | 搜索股票、ETF、场外基金 |
| `GET/POST/PATCH/DELETE /api/watchlist` | 股票和基金自选管理 |
| `GET/POST/PATCH/DELETE /api/groups` | Group 管理 |
| `GET /api/groups/{id}/series` | Group 历史归一曲线 |
| `GET/PUT/DELETE /api/holdings` | 单账户持仓 |
| `GET/POST/PATCH/DELETE /api/alerts` | 提醒规则 |
| `GET /api/alerts/hits` | 提醒命中记录 |
| `GET/POST/PATCH/DELETE /api/channels` | 通知渠道 |
| `POST /api/channels/{id}/test` | 渠道测试 |
| `GET /api/reviews/daily` | 简报列表和详情 |
| `POST /api/reviews/daily/run` | 手动生成简报 |
| `GET/PUT /api/settings` | 语言、AI、时间和通知设置 |
| `POST /api/quotes/batch` | 批量报价 |

统一返回以下字段：

- `value`
- `as_of`
- `source`
- `freshness`: `live | delayed | stale | estimated | official_nav`

## 8. 提醒与通知

### 8.1 提醒规则

- 每条规则只支持一个条件：价格或当日涨跌幅。
- 方向支持上穿/高于、下穿/低于。
- 默认每交易日最多触发一次。
- 可选择允许重复，并设置冷却时间。
- 自动提醒只在确认的交易日执行。
- 股票和 ETF 遵守各自市场交易时段。
- 场外基金盘中规则使用估值；没有估值时使用最近正式净值。

### 8.2 飞书

- 使用自定义机器人 Webhook。
- 支持可选签名密钥。
- 使用富文本卡片展示标的、规则、价格、涨跌幅、时间和数据状态。

### 8.3 阿里云短信

- 使用阿里云官方 SDK。
- 配置 AccessKey、签名、手机号和中英文模板。
- 模板参数固定为 `name`、`price`、`change`、`rule`。
- 用户需自行申请短信签名和中英文模板。
- 短信按运营商和阿里云规则收费。

### 8.4 投递可靠性

- 每个提醒命中先落库，再逐渠道投递。
- 每个渠道维护独立的 `pending/sending/delivered/retry/failed/blocked` 状态。
- 单渠道失败不影响其他渠道。
- 支持指数退避、手动重试和投递诊断。
- 成功投递后才更新命中记录的完成状态。

## 9. 每日持仓健康简报

### 9.1 调度

- 时区：`Asia/Shanghai`。
- 仅在 A 股交易日运行。
- 默认执行时间：`15:20`。
- 失败后 `15:28` 重试一次。
- 成功生成后不重复推送。
- 无持仓时跳过。

### 9.2 输入

- 持仓成本、数量、市值和浮盈亏。
- 当日行情和 20/60/120 日趋势。
- 股票、ETF、场外基金占比。
- 市场占比和集中度。
- 主要指数表现。
- 最近一次成功行情的时间。

### 9.3 输出

- 组合健康度摘要。
- 主要贡献和拖累。
- 集中度、分散度和市场暴露。
- 趋势变化。
- “继续持有/观察/减仓/加仓”的分析建议。
- 明确声明：仅供个人参考，不构成投资建议，不自动交易。

### 9.4 语言与通知

- 使用后端保存的界面语言生成内容。
- 简报可以在页面查看。
- 推送至设置中选择的飞书/短信渠道。
- SMS 只发送模板化的精简摘要，不发送完整 Markdown。

## 17. 假设

- 单用户自托管。
- 只支持 A 股 ETF，不扩展港股/美股 ETF。
- 场外基金没有连续交易价格，盘中估值不是正式净值。
- 阿里云短信账号、签名和模板由部署者自行配置。
- 当前免费行情源不提供 SLA，接受偶发限流、延迟和端点变化。
- 首版只做深色主题。
- 新版本从全新 `panwatch-v2.db` 开始，不迁移旧业务数据。
- 不删除旧数据库，不删除归档 tag。
