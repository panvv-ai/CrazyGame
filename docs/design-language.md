# CrazyGame 设计语言：极光工作台

## 定位

CrazyGame 不是交易终端，也不是营销首页。它是一个私人长期投资观测站。

视觉方向借鉴参考站的“环境光场 → 工作台”关系，但不复制其营销页结构：

- 学习：大面积冷色光场、真实明暗层次、玻璃材质细节、滚动中的环境变化。
- 学习：主动作区必须明亮、清晰、可立即使用。
- 拒绝：超大营销标题、首屏空白、必须滚动后才能操作的功能区。
- 保留：CrazyGame 的长期观察定位、中文涨跌语义、数据状态与风险边界。

产品主路径保持不变：

```text
行情 → 分类自选 → 加权组合 → 轻量持仓 → 提醒 → 每日复盘
```

## 视觉主题

### 光场

页面背景由五个固定层组成：

1. 深海军蓝基础色。
2. Canvas 绘制的蓝、青、紫极光团。
3. 低透明度极光雾层。
4. 远处渐隐的观测网格。
5. 一条穿过首屏的极光地平线与轻微颗粒。

极光会极慢漂移，并根据页面滚动改变纵向位置；这是整套界面唯一持续运动的装饰。所有效果都在 `prefers-reduced-motion` 下静止。

### 色板

核心颜色使用 OKLCH 语义变量，定义在 `frontend/src/crazygame/workbench.css`。

| Token | 角色 |
|---|---|
| `--color-paper` | 极光下的深海军蓝底色 |
| `--color-paper-raised` | 被光场托起的深色表面 |
| `--color-surface` | 常规玻璃面板 |
| `--color-surface-strong` | 一级工作台、导航与选中状态 |
| `--color-surface-high` | 高亮浮层与浅色甲板 |
| `--color-ink` | 主文本 |
| `--color-muted` | 次级正文 |
| `--color-faint` | 辅助标签与元数据 |
| `--color-accent` | 极光蓝紫，用于焦点与主要强调 |
| `--color-cyan` | 曲线、上下文与正向辅助光 |
| `--color-violet` | 第二辅助光 |
| `--color-rose` / `--color-mint` | 中文市场上涨 / 下跌 |

所有正文与图标必须在实际合成背景上保持可读。禁止把 8–10px 低对比度文字直接铺在近黑背景上。

### 字体

- Latin 与数字：Manrope Variable。
- 中文：PingFang SC、Hiragino Sans GB、Microsoft YaHei。
- 数据与代码：`--font-data`，仅用于价格、时间、状态和图表刻度。
- 页面标题保持罗马体、紧凑字距；不再使用 60px 级别的全局页头。

## 布局

### 页面控制栏

所有功能页顶部使用紧凑控制栏，而不是营销式 Hero：

- 左侧：短 eyebrow、28–42px 页面标题、一行说明。
- 右侧：当前状态与首屏主操作。
- 页面主工作区在桌面首屏内直接出现。

### 总览

- 顶部保留数据驱动的主组合面板。
- 左栏展示资产价值、当日变化和成员。
- 右侧直接展示真实组合曲线。
- 下方以不等宽 Bento 面板展示自选、复盘和最近提醒。

### 自选

- 股票与基金、市场范围使用两级胶囊筛选。
- 搜索框和截图识别保留为一级操作。
- 每张标的卡展示现价、当日涨跌、最近 31 个数据点的迷你走势。
- 拖拽排序、1 年详情、新建提醒和删除继续保留。

### 组合

- 左侧是组合导航，右侧是组合详情。
- 首屏展示当日、近 30 日、覆盖率和成员数。
- 曲线与成员权重同屏可读。

### 持仓

- 按币种分别汇总市值与未实现盈亏，不跨币种混算。
- 分布环按持仓数量展示市场构成，不伪造现金或汇率。
- 持仓表保留成本、现价、市值和浮动盈亏。

### 提醒

- 规则卡展示监听状态、阈值、当前值、条件接近度和冷却策略。
- 规则支持直接启停和完整编辑。
- 提醒频次合并为一个选择项：每天一次、每 30 分钟、每小时或每 6 小时。
- 新建规则时可选择“保存后立刻检查并执行一次”，默认关闭；立即检查仍遵守交易时段和冷却约束。
- 最近命中在规则视图右侧同步展示。

### AI 诊股

- 页面本身就是一个单屏工作台。
- 左侧是可搜索的问股会话。
- 顶部显示当前标的、行情状态与新建问股。
- 对话区使用真实 Markdown 内容，不伪造结构化证据。
- 输入甲板使用高亮浅色表面，始终位于桌面和移动端首屏内。

### 设置

- 保存是页头一级操作。
- 语言、AI 模型、新闻源、复盘计划、通知渠道分区展示。
- 通知渠道配置支持先测试、后保存，二者是明确分开的操作。
- 密钥字段永远保持掩码显示。

## 组件

### GlassPanel

- 1px 低亮边框。
- 18–24px 圆角。
- 1.5rem 左右背景模糊。
- 只在建立层级时使用。

### 发光输入甲板

- 使用 `--color-composer` 的浅色磨砂表面。
- 深色正文与深色占位文字。
- 容器获得焦点时显示完整外轮廓。
- 不做渐变文字，不使用低对比度半透明文本。

### 按钮

- 主操作：浅色高亮胶囊，深色文字。
- 次操作：玻璃底与细边框。
- 图标操作：至少 2.4rem 的视觉尺寸，并提供可读的 `aria-label`。
- 所有按钮、筛选和导航标签都不换行。

### 数据状态

行情状态、时间和来源必须与价格保持邻近：

- `live / delayed / stale / estimated / official_nav`
- `as_of`
- `source`

状态颜色只表达风险，不替代主数据颜色。

## 动效

- 极光背景：低速连续漂移，滚动只改变光场位置，不做夸张视差。
- 页面切换：420ms 淡入与轻微上移，仅触发一次。
- 卡片悬停：只做 2px 上浮。
- 焦点轮廓：立即出现，不做渐入。
- 极光以外的所有运动都应有明确目的；禁止大量入场、脉冲和滚动跟随。
- `prefers-reduced-motion` 下关闭所有空间运动。

## 文案

- 使用用户能控制的词汇，例如“添加提醒”，而不是“创建规则实体”。
- 空状态必须说明下一步。
- 错误说明发生了什么；不写空泛的“出错了”。
- 不承诺收益，不预测价格。
- 行情与 AI 内容继续标注时间、来源和限制。

## 视觉验收

- 1440 × 900 桌面截图。
- 1280 × 800 窄桌面截图，确认 AI 输入区无需滚动即可见。
- 390 × 844 移动端截图。
- 320、375、414、768px 宽度无横向滚动。
- 中英文各检查总览、自选、组合、持仓、提醒、AI 和设置。
- 检查空数据、行情失败、旧数据、场外基金估值四种状态。
