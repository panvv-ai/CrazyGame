# CrazyGame 设计语言：极光观测台

## 定位

CrazyGame 不是交易终端，也不是营销首页。它是一个私人长期投资观测站：

- 用户首先看到资产关系和趋势，而不是密集操作按钮。
- 数据状态、时间和不确定性始终可辨认。
- 视觉氛围高级但不妨碍阅读。

## 色板

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#050811` | 全局背景 |
| `--panel` | `rgba(16,23,41,.62)` | 毛玻璃面板 |
| `--text` | `#F7F9FF` | 主文本 |
| `--muted` | `rgba(226,232,255,.54)` | 正文与说明 |
| `--blue` | `#8EA7FF` | 主要强调色 |
| `--cyan` | `#81D8E8` | 辅助曲线色 |
| `--violet` | `#A78BFA` | 第二辅助曲线色 |

中文市场的上涨使用红色、下跌使用绿色；英文市场相反。颜色由 `html[lang]` 控制，不写死在组件中。

## 字体

- Latin 与数字：Manrope Variable，本地打包，不依赖 CDN。
- 中文回退：PingFang SC、Hiragino Sans GB、Microsoft YaHei。
- 标题使用 470–570 字重、紧凑字距。
- 正文保持 10–14px 的克制层级，关键数字可放大到 27–66px。

## 布局

- 桌面最大内容宽度 1380px。
- 悬浮胶囊顶栏，距离顶部 14px。
- 首页使用一个大型“组合观测”面板作为视觉主角。
- 其余内容使用二级玻璃面板和单线分隔。
- 自选与组合使用两级胶囊 tab：先区分股票/基金，再区分市场或基金类型。
- tab 只改变当前视图，不混合不同分类的标的或组合。
- 移动端 390px 以上必须可操作，底部保留五项主导航。

## 标志性元素

页面背景的“极光地平线”是唯一强视觉元素：

- 低饱和蓝紫径向光。
- 极淡的网格。
- 一条穿过首屏的细光带。
- 18 秒慢速呼吸，不使用持续视差。

其他元素保持安静。不要再叠加大量发光描边、彩色渐变按钮或炫技动画。

## 组件

### GlassPanel

- 1px、8% 白色边框。
- 24px 圆角。
- 24px 背景模糊。
- 顶部 4% 白色高光渐变。
- 只在需要建立层级时使用，不包裹每一个字段。

### 曲线图

- 默认显示 1 年。
- 单组使用时为面积曲线；组合详情最多叠加 5 条成分曲线。
- 不使用 K 线、蜡烛图或技术指标面板。
- 坐标文字低对比，保留十字线。

### 数据状态

每个行情数字附近显示：

- `live / delayed / stale / estimated / official_nav`
- `as_of` 时间

状态颜色只表达风险，不抢主数据颜色。

### 按钮

- 主操作：白底深色字，胶囊圆角。
- 次级操作：透明玻璃底和细边框。
- 危险操作：只在悬停或明确确认时显示红色。

## 动效

- 首屏元素依次渐显 600ms。
- 悬浮、抽屉和图表更新 160–240ms。
- 所有动画遵守 `prefers-reduced-motion`。
- 数据自动刷新不得触发布局跳动。

## 文案

- 使用用户能控制的词汇：“添加提醒”，而不是“创建规则实体”。
- 空状态必须说明下一步，例如“先添加一只股票或基金”。
- 错误说明发生了什么；不写空泛的“出错了”。
- 不承诺收益，不预测价格，不使用“稳赚”“精准抄底”等措辞。

## 视觉验收

- 1440 × 900 桌面截图。
- 390 × 844 移动端截图。
- 中英文各检查首页、自选、组合、提醒。
- 检查空数据、行情失败、旧数据、场外基金估值四种状态。
